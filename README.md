## Tech Stack

- Hugo
- HTML / CSS / JS

## How to run it Locally

1) Clone the Repo

2) Install Hugo

3) cd to the root of the repo

4) run:

```bash
hugo server -D
```

5) Then open:

```text
http://localhost:1313
```

# Operators Script

Operators are special symbols or keywords that are used to carry out computations and perform logical operations. This introduction will cover the types of operators in Python, including arithmetic, comparison, logical, bitwise, assignment, and special operators.

Arithmetic operators are used to perform basic mathematical operations such as addition, subtraction, multiplication, and division.

The “plus” symbol is used for addition. The - symbol for subtraction. The asterisk symbol for multiplication. The forward slash symbol for division.

The percent symbol for the modulo operator (which returns the remainder of dividing the left hand operand by right hand operand). The double asterisk symbol for exponentiation (or to the power of).

Finally, the double forward slash is for floor division (which is division that rounds down to the nearest integer).

Comparison operators in Python are used to compare two values and return a Boolean value (True or False). The double equals operator is used to check if two values are equal, while the exclamation point equals symbol checks if two values are not equal.

The greater than symbol operator is used to determine if the value on the left is greater than the value on the right, and the less than symbol operator checks if the value on the left is less than the value on the right.

The greater than or equal to operator evaluates if the value on the left is greater than or equal to the value on the right, and the less than or equal to symbol operator checks if the value on the left is less than or equal to the value on the right.

Logical operators are used to combine conditional statements. and returns True if both statements are true. or : returns True if at least one statement is true. not : reverses the boolean value
Bitwise operators perform operations on binary representations of integers.

NOTE: I’m not going to dive too deep into Binary, as it will blow out the scope of the video. All you need to know is that computers store text, images, videos etc as a stream of binary digits called bits, which is text composed of ones and zeros.

Python’s bitwise operators let you manipulate those individual bits of data at the most granular level. In this example, the value 10 is represented by the binary value 1010, and the value 3 is represented by the value 0011. The ampersand symbol represents the bitwise AND value. The pipe symbol represents the bitwise OR operator. Finally the circumflex symbol represents XOR, while the tilde symbol represents NOT.

Assignment operators are used to assign values to variables.

For fun, let's count the number of times I say assign in the next section. The equals symbol is for a simple assignment. The plus equals symbol add’s and assigns. The minus equals symbol subtracts and assigns. The asterisk equals symbol multiplies and assigns. The forward slash equals symbol divides and assigns. The percent equals symbol modulus and assigns.

The double asterisk symbol exponentiates and assigns. The double forward slash symbol applies floor division and assigns.

Python includes some special operators like identity and membership operators. Starting with identity operators, is : Evaluates to True if the variables on either side refer to the same object. is not : Evaluates to True if the variables on either side do not refer to the same object.

Next up, membership operators. in : Evaluates to True if a value is found in the sequence. not in : Evaluates to True if a value is not found in the sequence.
